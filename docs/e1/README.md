# Е1 · Технологичен профил и работеща минимална система (раздел 1.10, 23 %)

Ключов въпрос: може ли системата да бъде изградена, проверена и разгърната от човек,
който вижда хранилището за пръв път?

## Какво се предава
- [ ] Технологичен профил по **седемте слоя** (Фигура 1.2), включително отсъстващите:
      потребителски интерфейс · интеграция и API · рамка · език и среда за изпълнение ·
      хранилище на данни · контейнер и оркестрация · инфраструктура
- [ ] Обосновка на всеки избор по **седемте критерия** (1.1): зрялост · общност ·
      време за смяна · наличие на кадри · съответствие с ISO/IEC 25010 ·
      оперативна съвместимост · наблюдаемост
- [ ] За всеки слой: отхвърлена алтернатива и цена на смяната
- [ ] Избран архитектурен стил (монолит–микросервизи) с назована цена
- [ ] ADR: контекст, решение, последици, отхвърлена алтернатива
- [ ] Ред за криптографията: къде се използва и може ли алгоритъмът да се смени (1.10-6)
- [ ] Работеща минимална услуга, опакована в контейнер, с приковани версии на образите
- [ ] Конвейер, който я изгражда, проверява и произвежда артефакт
- [ ] Машинно четим списък на съставките (SBOM)
- [ ] Указания за изграждане, изпълнени наново на чиста машина
- [ ] Без тайни в историята на хранилището
- [ ] Поне една диаграма с ред: от кой от шестте вида е и на какъв въпрос отговаря
- [ ] Оценка за следващите етапи → [дневник](../dnevnik-ocenki.md)
- [ ] Декларация за ИИ → [таблица](../ai-deklaraciya.md)
- [ ] Допълнителното нефункционално изискване по жребий (Приложение Й) — **чака отговор от преподавателя**

## Оценява се по
пълнота спрямо седемте слоя · обоснованост спрямо седемте критерия · работоспособност
(трето лице изгражда по указанията) · проследимост (от SBOM се вижда какво влиза в артефакта).
