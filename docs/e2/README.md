## Вход за STRIDE от прегледа на кода (2026-11-27)
- **Подправяне на самоличност (S):** услугата приема показание от името на всеки електромер,
  без да проверява кой го изпраща. Временна мярка: портовете са отворени само за 127.0.0.1.
- **Подправяне на данни (T):** едновременни показания можеха да запишат намаляващ регистър —
  поправено със заключване по електромер; правата в базата забраняват промяна и изтриване.
